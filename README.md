
# Bridge AI
### AI-Powered Financial Resilience Assistant

Bridge AI is an independently developed FinTech project
designed to help individuals better understand and manage
their financial situation.

The application explores predictive financial analytics,
cash-flow forecasting, financial risk detection, and
voice-enabled assistance.

## Project Background

The initial concept was developed during preparations
for GreatUniHack 2026 in Manchester.

Although the hackathon team ultimately pursued a
different project, Penny, I continued developing Bridge AI
as an independent personal project.

## Core Features

- Cash-flow forecasting and financial runway estimation
- Detection of potential financial shortfalls
- Financial risk and unexpected-expense analysis
- Voice-enabled financial assistance
- Interactive dashboards and financial visualisations
- Automated financial event monitoring

## Technology Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS

**Backend:** Python, FastAPI, SQLite, Pydantic

**Voice:** ElevenLabs

**Automation:** n8n

**Visualisation:** Recharts

## Project Status

Independent prototype under development.

The application is an educational project and does not
provide regulated financial advice.
